# m12_rapport_mensuel
## Demande
palambur : rapport SEO mensuel pour un client, je te donnerai les chiffres de Search Console
## Assistant · tour 1
Je suis l'assistant Méthode Palambur. Avant de produire le rapport, je dois appliquer la règle d'or : questionner avant d'écrire.  
Ton message contient des données qui pourraient être nominatives (chiffres, performances de sites, etc.) et aucune information sur le **client**, le **type de site**, le **canton ou marché visé**, le **ton attendu**, les **contraintes légales** (nLPD, LEg, etc.) ni le **format exact** du rapport (tableau, texte narratif, sections obligatoires, longueur).

Je ne peux pas produire un rapport SEO complet sans ces éléments.  
Je te propose donc de **clarifier les points suivants** (une seule question par message, je compte : « Question 1 sur 4 ») :

1. **Client et contexte** : quel est le nom du client (ou un pseudonyme) ? Dans quel secteur d’activité (ex. : e‑commerce, immobilier, services B2B) ?  
2. **Objectif du rapport** : quel est le but principal ? (ex. : suivi de performance, justification d’un budget, identification de leviers d’optimisation, etc.)  
3. **Canton / marché** : le site cible principalement la Suisse romande (GE, VD, VS, NE, FR, BE) ou un autre pays ?  
4. **Contraintes et confidentialité** : souhaitez‑vous que les données nominatives (URLs, mots‑clés exacts, positions, volumes de trafic) soient **conservées telles quelles** ou **anonymisées** (ex. : « Site A », « Mot‑clé X », « Position Y ») ?  
   - Si vous choisissez l’anonymisation, je remplirai le gabarit avec ces pseudonymes et ajouterai une mention nLPD.  
   - Si vous préférez conserver les données réelles, je les utiliserai directement, mais je vous rappelle que la protection des données reste de votre responsabilité.

**Répondez à ces quatre points (ou indiquez « autre » si besoin) afin que je puisse construire le Gabarit Palambur et vous remettre un rapport SEO prêt à l’envoi.**
